# M1 — доменное ядро

Документ описывает границу M1. Хранение и импорт, упомянутые здесь как последующая
работа, реализованы в M2; см. [описание M2](persistence-import.ru.md).

Реализация находится в `ResearchLab.Domain` и использует только стандартную
библиотеку .NET. Прикладных сценариев, хранения, миграций, импорта, запуска команд
и UI пока нет. Модель доступна через публичный API и тесты; готового пользовательского
сценария ещё нет. Все данные тестов — явно синтетические примеры.

## Идентификаторы и параметры

- Project, Experiment и Run используют отдельные неизменяемые обёртки над Guid.
  Конструкторы и входы агрегатов отклоняют пустые ID, включая default структуры.
  Идентификатор Project не вычисляется из пути workspace.
- `ParameterValue.From` принимает только Int32, конечный Double, Boolean и String.
  Парсинга, неявных преобразований и зависимости от локали нет. Null, изменяемые
  объекты и неподдерживаемые числовые типы вызывают `DomainException`.
- Имена непустые и регистрозависимые (ordinal). Повторные определения и неизвестные
  входные имена отклоняются. Числовые границы включительны и применимы только к числам.
  Набор разрешённых значений непустой; значения соответствуют типу и границам.
  Значение по умолчанию проходит те же проверки, что и переданное явно.
- Корректное значение по умолчанию удовлетворяет отсутствующему обязательному
  параметру. Необязательный параметр без default остаётся отсутствующим. Некорректное
  явное значение не заменяется default. Ошибки имеют стабильный код и пояснение.

## Владение снимками

`Run.Create` требует Experiment, соответствующий TaskSnapshot и корректные параметры.
Определение эксперимента, аргументы/тайм-аут задачи, проверенные параметры, исходный
код и окружение фиксируются при создании Run, до запуска процесса. Коллекции
копируются и доступны только для чтения; элементы неизменяемы. `Experiment.Revise`
заменяет определение, не меняя снимки ранее созданных Run.

Неизвестные Git SHA и состояние рабочего дерева сохраняются как null. Метаданные
окружения передаёт вызывающий код; Domain не исследует машину и не делает вывод
о точной воспроизводимости. TaskSnapshot описывает команду, но не разрешает её
исполнение. Поиск доверенной конфигурации, наличие исполняемого файла и проверка
границ путей относятся к последующим прикладным и инфраструктурным этапам.

## Жизненный цикл и данные

- Согласованный цикл EN/RU включает `Created → Failed` при ошибке запуска.
  `Start` требует положительный ID процесса; факт успешного запуска ОС сможет
  подтвердить только будущий сервис исполнения.
- Успех требует кода выхода 0 и явного подтверждения завершённой проверки результатов.
  Ошибка требует причины; до запуска нет кода выхода, времени старта и длительности.
  При ошибке обработки результатов код выхода может быть равен 0.
- Отмена до старта допустима. Тайм-аут возможен по истечении заданного интервала
  после старта. Interrupted доступен только из Running. Терминальные состояния
  неизменяемы, включая повторную попытку завершения.
- Время передаёт вызывающая сторона; Domain нормализует его в UTC и отклоняет
  переходы назад по времени. Длительность определена только после старта и завершения.
- Каждое изменение Run требует ожидаемой `Version` и увеличивает её при успехе.
  Ошибка не меняет состояние. Это защищает от последовательных устаревших изменений;
  агрегат не является потокобезопасным. Прикладные сервисы должны сериализовать
  изменения, а хранилище M2 — атомарно сверять версии при сохранении разных экземпляров.
- Метрики добавляются через Run только в Running: значения конечные, имена непустые,
  единицы измерения отсутствуют либо непустые. Единицы внутри серии совпадают точно
  (ordinal), включая отсутствие единиц; преобразований единиц нет. Sequence начинается
  с 1 и задаёт порядок поступления по всему Run независимо от повторяющихся или
  неупорядоченных шагов Int64 и времён. Точки неизменяемы. Оставшийся вывод нужно
  обработать до терминального перехода; принятые точки сохраняются и при ошибке Run.
  Парсер протокола и лимиты приёма относятся к M4.

## Проверки и отложенная работа

Тесты покрывают ограничения параметров, default, владение снимками, каждый доступный
переход статуса, неизменяемость завершённых Run, неверное время/метаданные, устаревшие
версии, конечность метрик, единицы и порядок. Публичного перехода обратно в Created
нет; setter статуса закрыт. Архитектурный тест допускает только используемые Domain
сборки стандартной библиотеки.

Команды restore/build/test/format приведены в README. Конкурентное сохранение,
реальный жизненный цикл процессов, границы путей артефактов и безопасность экспорта
в этом этапе намеренно не заявляются реализованными или проверенными.
