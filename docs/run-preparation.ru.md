# M3.1a — Подготовка запуска

`new RunPreparation(catalog).PrepareAsync(experimentId, parameters, cancellationToken)`
использует тот же экземпляр `ProjectCatalog`, который хранит доверие владельца в текущей
сессии. Сервис загружает Experiment и Project, проверяет параметры по правилам Domain
(включая defaults и отсутствие необязательных значений), затем вызывает `GetTrustedTaskAsync`.
Сохраняются существующие проверки конфигурации, принадлежности путей workspace,
символических ссылок и fingerprint исполняемого файла.

Неизменяемый `PreparedRun` содержит определения эксперимента/задачи, копию проверенных
параметров, рабочую директорию, разрешённый путь исполняемого файла, fingerprint доверия,
время подготовки и доступные сведения об ОС/архитектуре процесса. Аргументы остаются
буквальными строками; параметры хранятся отдельно без подстановки в команды.
Секреты окружения не считываются.

Отсутствующие объекты дают `CatalogException` с кодами `ExperimentNotFound` / `ProjectNotFound`.
Ошибки доверия, путей и конфигурации сохраняют существующие коды каталога; ошибки параметров —
понятные коды и сообщения `DomainException`. Новые иерархии ошибок, зависимости, схема
хранения и изменения контрактов M0–M2 не вводятся.

Подготовка не запускает процессы, включая Git. Происхождение исходников явно неизвестно:
все поля `SourceSnapshot` равны null, воспроизводимость не заявляется. Сервис не создаёт
и не сохраняет Run, не изменяет его жизненный цикл и не выделяет выходную директорию.
Результат — данные для будущего исполнителя, а не сохранённый Run в состоянии `Created`.

Будущий этап исполнения должен собрать доступные сведения об исходниках, сохранить новый
Run с зафиксированными определениями/параметрами и непосредственно перед запуском повторно
сверить текущий fingerprint задачи со снимком. Подготовка не даёт бессрочного разрешения
на исполнение и не устраняет гонки файловой системы. Запуск процесса, проверка прав исполнения,
выходная директория, отмена, история и восстановление остаются за пределами задания.
